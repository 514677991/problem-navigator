# Skill contract fixtures · 技能契约样例

These files are maintained compatibility fixtures used by the automated tests. Some
record historical RED/GREEN observations and explicitly retired behavior. They are
not user setup instructions, live API benchmarks or transcripts of current host E2E
runs. The current authority is the shipped
[workflow control contract](../../skills/problem-navigator/references/workflow-control.md).

这些文件是自动化测试使用的兼容性样例，部分保留历史 RED/GREEN 观察及已弃用行为。
它们不是用户安装指南、线上 API 质量基准或当前宿主的真实全流程运行记录。当前规则以
[随插件分发的工作流契约](../../skills/problem-navigator/references/workflow-control.md)为准。
