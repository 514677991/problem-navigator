# Problem Navigator v2.1.0

## English

Problem Navigator's first public release provides a general-purpose problem-analysis workflow built from shared skills and a local Python/MCP research core. It supports **GENERAL** and **PRODUCT_SOFTWARE** work, from clarification and research through decisions and solution design, ending in reports, PRDs, or technical specifications.

- **9 skills** coordinate the workflow; **4 MCP tools** provide `web_research_status`, `web_search`, `web_fetch`, and `web_map`.
- **One download:** `problem-navigator-2.1.0.zip`, with checksum file `problem-navigator-2.1.0.zip.sha256`. The bundle contains one shared core, English/Chinese instructions, and optional Codex integration metadata.
- **MIT licensed.** License and attribution are included as `LICENSE` and `NOTICE.md`.

Use Python **3.11+** and `uv`. Keep `skills/` and `mcp/` together after extraction; follow `README.md` and `HOST_INSTRUCTIONS.md`. The full workflow requires an AI host that can load complete skill files and references, read/write local artifacts, execute Python helpers, and obtain clarification and document acceptance. It ends at analysis/design, without implementation or deployment.

The MCP server uses **local stdio**. MCP-only access exposes the four research tools, not the complete workflow; remote-HTTP-only clients cannot connect directly. The bundle does not imply universal one-click installation or verified end-to-end behavior in every host.

Public Web research requires your own **Brave, Exa, or Firecrawl API keys** for the chosen routes. Authorized queries, URLs, and filters go to the selected provider; applicable provider and host/model charges are yours. **`NONE` research needs no provider keys or research network calls**; initial dependency downloads and host/model connectivity are separate.

## 中文

这是 Problem Navigator 的首个公开 Release。项目由共享技能与本地 Python/MCP 研究核心组成，支持 **GENERAL（通用问题）**和 **PRODUCT_SOFTWARE（产品/软件问题）**，覆盖澄清、调研、决策与方案设计，交付报告、PRD 或技术规格。

- **9 个技能**协同工作流；**4 个 MCP 工具**为 `web_research_status`、`web_search`、`web_fetch`、`web_map`。
- **只需一个包：**`problem-navigator-2.1.0.zip`，附校验文件 `problem-navigator-2.1.0.zip.sha256`。包内包含一份共享核心、中英文说明和可选 Codex 集成元数据。
- **采用 MIT 许可证。**许可与署名见包内 `LICENSE`、`NOTICE.md`。

需要 **Python 3.11+** 和 `uv`。解压后保持 `skills/` 与 `mcp/` 同根，按照 `README.zh-CN.md` 和 `HOST_INSTRUCTIONS.md` 使用。完整工作流要求 AI 宿主能够完整加载技能及引用、读写本地产物、执行 Python 工具，并进行澄清与文档接受。工作流止于分析和设计，不执行实现或部署。

MCP 服务使用**本地 stdio**。仅接入 MCP 会得到四个研究工具，不会自动获得完整工作流；仅支持远程 HTTP 的 MCP 客户端不能直接连接。单一发行包不代表所有宿主都可一键安装或已完成端到端验证。

公开网页研究需要为所选路由提供自己的 **Brave、Exa 或 Firecrawl API 密钥**。经授权的查询、URL 与过滤条件会发送至所选服务商，适用的服务商及宿主/模型费用由用户承担。**`NONE` 研究无需服务商密钥，也不发起研究网络调用**；首次依赖下载与宿主/模型连接另行适用。
