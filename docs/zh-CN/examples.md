# 提示词与输出示例

请先按照[通用入门指南](quickstart.md)或宿主适配加载入口技能及其引用。以下为说明性的输出片段，并非真实端到端运行记录。每个中文示例与英文对应项使用相同范围和事实。插件可能追问影响结果的关键问题，并在最终接受前提供预览。

## 1. 离线理解通用问题

**提示词**

> 使用 problem-navigator，用中文回答。只根据这些记录，说明每周例会为什么超时：计划时长 30 分钟；最近三次实际用了 45、50、55 分钟；每次会议中途都有新增议题。不要联网，也先不要选择解决方案。输出研究报告，区分事实、推断与未知。

**路径：** `UNDERSTAND` + `GENERAL` → `RESEARCH_REPORT`；后端 `NONE`。

**报告片段示意**

> **FACT（事实）：** 三次记录中的会议分别比计划超出 15、20、25 分钟。来源：用户提供的会议记录，时长条目。
>
> **INFERENCE（推断）：** 新增议题可能导致超时，但记录尚不足以确立因果关系。
>
> **UNKNOWN（未知）：** 各议题实际用时、原议程是否合理，以及参与者是否认为额外时间有价值。
>
> **需要补充的证据：** 分议题计时与参与者的说明。本报告用于理解缺口，尚不对解决方案排序。

不应虚构公开来源或服务商调用。所提供的记录能说明用户报告了什么，并不等于对会议情况进行了独立核验。

## 2. 定义产品，仅交付 PRD

**提示词**

> 使用 problem-navigator，用中文回答。我们需要一个会议室预约产品，用于一处办公室的四间共享会议室。员工可以查看空闲情况、预约空闲时段和取消自己的预约；前台可以取消任何预约；冲突预约必须被拒绝。只使用这份简述，不要联网。协助解决剩余产品决策，仅交付 PRD，使用稳定的需求与验收 ID。不要选择实现技术栈。

**路径：** `DECIDE` + `PRODUCT_SOFTWARE` → `PRD_ONLY`；后端 `NONE`。

**`01-prd.md` 片段示意**

> **REQ-001 — 防止预约冲突：** 同一会议室不能存在时间重叠的有效预约。
>
> **AC-001：** 已有某会议室的有效预约时，如果另一请求的时间区间与之重叠，则拒绝新请求，并保持已有预约不变。
>
> **REQ-002 — 取消权限：** 员工可以取消自己的预约；前台可以取消任何预约。
>
> **待定事项：** 接受 PRD 前，需确认办公时间，以及相邻预约是否允许共享时间端点。

完整预览包含已约定的用户、范围、适用约束与验收标准。该端点不要求选择架构，也不要求生成技术规格成员。产品待定事项须在接受前解决，或明确保留为限制。

## 3. 解决纯技术设计问题

**提示词**

> 使用 problem-navigator，用中文回答。我们已有一个服务，会收到重复投递的事件。给定契约规定每个事件具有稳定 ID，重复投递不得重复产生副作用，只有持久化处理完成后才允许确认。存储系统支持原子事务。只使用这些约束，比较设计备选，仅输出技术方案规格。不要创建 PRD、代码或实现任务。

**路径：** `DECIDE` + `PRODUCT_SOFTWARE` → `TECHNICAL_SPEC_ONLY`；后端 `NONE`。

**`01-technical-solution-spec.md` 片段示意**

> **DES-001 — 持久化重复检测：** 比较“将事件 ID 与副作用放入同一原子事务”与“使用独立去重存储”两个选项。
>
> **设计成立条件：** 同一事务方案仅在相关副作用能够参与该事务时成立；外部副作用仍是尚未解决的边界。
>
> **AC-001：** 重放已完成事件时，持久化业务结果保持不变。
>
> **AC-002：** 仅在相关持久化状态提交后发送确认。
>
> **UNKNOWN（未知）：** 事件 ID 的保留时长，以及是否存在外部副作用。

最终设计取决于实际备选、澄清后的边界和用户决策。不虚构 PRD 标识。验收标准描述行为，交付物不包含测试代码。

## 可选：加入网页证据

[配置服务商](configuration.md)后，可在请求中补充：

> 使用公开官方文档核验与本设计有关的当前约束。研究前说明查询/URL 范围及所选服务商路由。不要在外发查询中包含机密系统名称；区分来源事实与推断，保留精确引用和获取日期。

预期新增内容包括有来源支撑的发现、操作回执，以及来源缺失或被截断时的限制说明。单独的 `web_research_status` 不是研究结果。若明确偏好宿主内置研究工具，请在提示词中写明选择与范围。

要切换输出语言，可加入“最终报告请用英文”或“Write the final report in Chinese”。翻译正文时，结构字段、枚举值、ID、规范文件名和原始引用保持不变。
