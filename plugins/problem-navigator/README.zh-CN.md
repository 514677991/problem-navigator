# Problem Navigator｜问题导航

由共享技能与本地 Python/MCP 研究核心组成的通用 AI 插件，将通用问题及产品/软件问题整理为有证据支撑的报告和设计规格，支持中文与英文。发行版本 `2.1.0`；研究 MCP `0.2.0`；MIT 许可证。

这是唯一发行包 `problem-navigator-2.1.0.zip`。保持 `skills/`、`mcp/` 与 `release.json` 位于同一安装根目录。共享核心仅一份，可选 Codex 元数据及指南放在同一个包内。它不是所有宿主统一的一键插件导入格式。

## 快速开始

使用能够完整读取技能文件与引用、读写本地产物、执行本地 Python 命令，并可进行澄清与文档接受的 AI 宿主。准备 Python 3.11+ 与该宿主 `PATH` 中的 `uv`。在本包根目录运行：

```sh
uv sync --locked --project mcp/web-research-mcp
```

首次准备可能下载依赖。随后让宿主执行：

> 完整读取此安装目录中的 `skills/problem-navigator/SKILL.md` 及其必需引用，遵循该工作流，并在路由时加载相邻阶段技能。用中文回答。只使用这些记录：一场计划 30 分钟的会议用了 45 分钟，中途新增两个议题。不要联网。输出研究报告，区分事实、推断与未知。

若安装位置不在宿主当前工作区，请指定绝对安装路径。原生技能发现是可选的：对具备所需文件与命令能力的宿主，明确读取文件也是集成方式。`$` 或 `/` 快捷语法属于宿主机制，不是核心要求。

离线研究选择 `NONE`，跳过服务商配置检查，不进行研究网络调用。宿主/模型正常连接与首次依赖下载另行适用。所提供的陈述保留来源，不自动视为已独立核验。

完整宿主要求、阶段加载、MCP 注册、密钥配置与限制见 [HOST_INSTRUCTIONS.md](HOST_INSTRUCTIONS.md)。

## 成果与语言

| 请求 | 端点与结果 |
|---|---|
| 理解问题 | `UNDERSTAND` → `RESEARCH_REPORT` |
| 确定通用方案 | `DECIDE` + `GENERAL` → `FORMAL_DOCUMENT` |
| 设计完整产品/软件方案 | `DECIDE` + `PRODUCT_SOFTWARE` → PRD 与技术规格 |
| 仅产品需求 | `PRD_ONLY` → `01-prd.md` |
| 仅技术设计 | `TECHNICAL_SPEC_ONLY` → `01-technical-solution-spec.md` |
| 明确约定的规格包 | 可选 `FINAL_SPEC_PACKAGE` |

需要 PRD 时，说明用户、行为、约束和验收需要，并要求仅交付 PRD。纯技术问题可要求仅技术规格，不创建 PRD。成果止于分析/设计；实现代码与部署不在工作流范围。文档在明确接受前保持预览状态。

中文和英文同等支持。正文先遵循当前明确语言选择，再遵循适用的先前偏好，否则跟随当前请求语言。只限定最终文档的偏好不会改变访谈语言。机器字段、枚举、ID、文件名和原始引用保持不变。

## 网页研究、费用与限制

网页研究使用用户自备的 Brave、Exa 或 Firecrawl 密钥，以及宿主中配置的本地 stdio MCP 连接。MCP 仅暴露研究工具，连接工具不会安装完整工作流。没有本地文件/命令访问的纯聊天环境无法执行完整工作流；仅支持远程 HTTP MCP 的宿主不能直接连接此服务。

经授权的查询、公开 URL、域名与相关请求选项会发送给所选服务商。核心每次调用选择一条路由，不会静默切换服务商。密钥、宿主/模型访问以及适用服务商费用由你负责。工作流调用预算不是金额上限。不要在外发请求中包含机密材料。宿主内置研究需要覆盖相应范围的明确授权。

同一个包支持手动加载核心与可选 Codex 适配。Codex 指南位于 `adapters/codex/README.zh-CN.md`；包根的 `.agents/plugins/marketplace.json` 指向包根，`.codex-plugin/plugin.json` 内联 MCP 注册，无需另下 Codex 包。

本集成不声称已在所有宿主完成端到端验证。结构、模拟服务商、工作流、压缩包和 stdio 自动检查不能证明线上服务可用或宿主完整行为。此处未提供 Claude Code 或其他宿主的原生适配。

遇到失败时，保留安全错误码与请求 ID，在本地核对所选路由的配置和额度，请求恢复前保留工作流产物。报告中不要放真实凭据或私人文档。若源仓库平台启用私密漏洞报告，请使用该渠道；否则先请求私密渠道，不公开敏感细节。
